Method and limitations

Regression: log cargo on Piraeus × post, with port × quarter-of-year fixed effects and calendar-quarter fixed effects. Standard errors are clustered by port.

Event normalization: the clean-pre path compares each quarter with the average fully untreated observation from the same season. The Q2 view shifts that same path so 2016 Q2 equals zero.

Key assumption: absent the transfer, Piraeus would have followed the selected European comparison ports after allowing for fixed seasonal patterns. The pretrend test and donor sensitivity help assess—but cannot prove—this assumption.

Inference: there are only four to eight port clusters depending on the donor pool. Several clustered event-study covariance matrices required a numerical positive-semidefinite correction. Confidence intervals and p-values should therefore be interpreted cautiously.
